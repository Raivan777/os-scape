# OS-Scape: The Core Simulation Game

Game simulasi sistem operasi berbasis web. Pemain adalah manusia yang diculik alien dan harus mengatur sumber daya komputer kapal (OMNI) melalui 5 stage untuk kabur.

Final Project Sistem Operasi, Ganjil 2026/2027 (Kategori B: Aplikasi Simulasi).

## Stage
1. The Queue Manager: penjadwalan proses (FCFS, SJF, Round Robin)
2. The Data Courier: threads dan IPC (Pipe, Message Queue, Socket)
3. The Parallel Builder: konkurensi (begin-end, parbegin-parend, fork/join)
4. The Traffic Controller: sinkronisasi (Mutex, Semaphore, Monitor)
5. The RAM Tetris: manajemen memori (First-Fit, Best-Fit, Worst-Fit)

## Cara menjalankan
Buka `index.html` di browser (klik dua kali). Tanpa instalasi.

## Struktur
- `js/engine/`: logika algoritma murni (tanpa tampilan)
- `js/stages/`: tampilan dan gameplay tiap stage
- `js/results.js`: perbandingan metrik
- `css/`, `assets/`, `docs/`
